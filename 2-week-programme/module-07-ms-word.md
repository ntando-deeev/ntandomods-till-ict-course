## 📖 Lesson 7.1 — Getting Started with Microsoft Word (45 minutes)

### Opening Word
1. Click Start → type "Word" → press Enter
2. Choose "Blank Document"
3. The Word window opens

### The Word Interface
```
┌──────────────────────────────────────────────┐
│  TITLE BAR — shows document name             │
├──────────────────────────────────────────────┤
│  RIBBON — tools: Home, Insert, Layout, etc.  │
├──────────────────────────────────────────────┤
│                                              │
│         DOCUMENT AREA — type here           │
│                                              │
├──────────────────────────────────────────────┤
│  STATUS BAR — word count, page number        │
└──────────────────────────────────────────────┘
```

### Saving Your Document
- **Ctrl + S** — Save (overwrites existing file)
- **Ctrl + Shift + S** — Save As (saves with new name/location)
- Always save in a logical folder with a clear name
- Example: "Invoice_OK_Supermarket_June2026.docx"

## 📖 Lesson 7.2 — Formatting Text (60 minutes)

### Basic Formatting Tools (on the Home Ribbon)
| Tool | Shortcut | Effect |
|------|----------|--------|
| **Bold** | Ctrl + B | **Makes text bold** |
| *Italic* | Ctrl + I | *Slants text* |
| Underline | Ctrl + U | Underlines text |
| Font size | — | Changes text size |
| Font color | — | Changes text colour |
| Align Left | Ctrl + L | Text starts from left |
| Centre | Ctrl + E | Text centred |
| Align Right | Ctrl + R | Text from right |

### Font Sizes for Business Documents
- **Headings:** 14–16pt Bold
- **Body text:** 11–12pt Regular
- **Standard business font:** Calibri or Arial

### Paragraph Spacing
- Press **Enter** once for a new line
- Press **Enter** twice for a new paragraph
- Use the "Line Spacing" button to set spacing to 1.15 or 1.5

## 📖 Lesson 7.3 — Inserting Tables & Bullet Points (45 minutes)

### Inserting a Table
1. Click **Insert** on the ribbon
2. Click **Table**
3. Drag to choose number of rows and columns
4. Click to insert

**Example — Simple Invoice Table:**
| Item | Quantity | Unit Price | Total |
|------|----------|-----------|-------|
| Bread | 2 | $0.90 | $1.80 |
| Milk 2L | 1 | $1.50 | $1.50 |
| Sugar 2kg | 1 | $2.00 | $2.00 |
| **TOTAL** | | | **$5.30** |

### Bullet Points
1. Click where you want the list
2. Click the **Bullet Point** button on Home ribbon
3. Type your first point and press Enter
4. Each new line gets a bullet

### Numbered Lists
- Same process but click the **Numbered List** button instead

## 📖 Lesson 7.4 — Printing a Document (45 minutes)

### Before Printing — Print Preview
1. Press **Ctrl + P**
2. A preview of your document appears on the right
3. Check that everything looks correct

### Print Settings
- **Printer:** Select the correct printer from the dropdown
- **Copies:** Enter how many copies you need
- **Pages:** Print all, or specific pages (e.g. "2-4")
- **Orientation:** Portrait (tall) or Landscape (wide)
- **Paper size:** A4 is standard in Zimbabwe

### Printing
1. Once settings are correct — click **Print**
2. Wait for the printer to finish
3. Collect your document promptly
