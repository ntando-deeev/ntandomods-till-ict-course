## 📖 Lesson 3.1 — Processing a Complete Sale (60 minutes)

### The 10-Step Sale Process

```
STEP 1:  Greet the customer warmly
STEP 2:  Scan all items one by one
STEP 3:  Check screen — make sure all items are correct
STEP 4:  Announce the total to the customer
STEP 5:  Ask: "How would you like to pay?"
STEP 6:  Receive payment
STEP 7:  Process payment on the system
STEP 8:  Give change (if cash)
STEP 9:  Print and hand over receipt
STEP 10: Thank the customer and say goodbye
```

### Greeting Script
> "Good morning/afternoon, welcome! Did you find everything you were looking for today?"

### Closing Script
> "Your total is $12.50. Thank you for shopping with us, have a wonderful day!"

## 📖 Lesson 3.2 — Payment Methods in Zimbabwe (45 minutes)

| Method | How to Process |
|--------|---------------|
| **USD Cash** | Count notes, enter amount, system calculates change |
| **ZiG Cash** | Same as USD — enter ZiG amount |
| **EcoCash** | Customer dials *151*2*amount*merchant_code# — wait for confirmation SMS |
| **OneMoney** | Similar to EcoCash — different USSD code |
| **Zipit (ZB, CBZ etc)** | Customer transfers via banking app — check confirmation |
| **Visa/Mastercard** | Swipe or tap card on card machine — wait for APPROVED |

### Checking EcoCash Payment
1. Customer sends EcoCash to your merchant number
2. You receive an SMS confirmation on the merchant phone
3. **Only after you see the SMS** — complete the sale
4. Print receipt — EcoCash reference number goes on receipt

> ⚠️ NEVER release goods before confirming payment. Fake confirmation screenshots are a common fraud.

## 📖 Lesson 3.3 — Processing Returns & Exchanges (45 minutes)

### When a Customer Returns an Item

**Store Return Policy (typical Zimbabwe retail):**
- Item must be returned within 7 days
- Original receipt must be presented
- Item must be unused and in original packaging
- Manager approval required for refunds over $10

### Steps to Process a Return
1. Check the customer's receipt
2. Verify the item matches what was bought
3. Check the return is within the allowed period
4. Call supervisor for approval
5. Scan the item on the RETURN function in POS
6. Choose refund method (cash, store credit, exchange)
7. Issue a return receipt
8. Update your cash if giving cash refund

## 📖 Lesson 3.4 — Voiding a Transaction (45 minutes)

A **void** cancels a transaction that has NOT yet been finalised (before payment is received).

### When to Void
- Customer changes their mind before paying
- Wrong item scanned and customer does not want it
- System error during scanning

### Steps to Void
1. Do NOT proceed with payment
2. Press the **VOID** or **CANCEL** button on POS
3. A supervisor may need to enter their override PIN
4. The system cancels all scanned items
5. The receipt printer may print a VOID receipt — keep it
6. Start a fresh transaction

> ⚠️ Every void must be recorded in the void log. If too many voids happen on your till, management will investigate.

### Void vs Refund
| | Void | Refund |
|--|------|--------|
| **When** | Before payment | After payment is completed |
| **Money changes hands** | No | Yes |
| **Supervisor needed** | Sometimes | Usually yes |
