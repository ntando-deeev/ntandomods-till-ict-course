## 📖 Lesson 6.1 — What is ICT? (45 minutes)

**ICT** stands for **Information and Communication Technology**.

It includes all the tools and systems used to store, send, and process information:
- Computers and laptops
- Mobile phones and tablets
- The internet
- Printers, scanners, cameras
- Software (Word, Excel, WhatsApp, email)

### Why ICT Matters in Zimbabwe Today
- Almost every business uses computers for records, invoices, and communication
- Banks, shops, clinics, schools — all run on ICT
- WhatsApp Business is used by millions of Zimbabwean traders
- Job adverts often say "computer literacy required"
- ICT skills = more job opportunities and better pay

## 📖 Lesson 6.2 — Parts of a Computer (60 minutes)

### Input Devices (send information TO the computer)
| Device | Function |
|--------|----------|
| Keyboard | Type text and commands |
| Mouse | Point and click on screen |
| Scanner | Digitise documents |
| Microphone | Record voice |
| Webcam | Video and photos |

### Output Devices (send information FROM the computer)
| Device | Function |
|--------|----------|
| Monitor | Display screen output |
| Printer | Print documents |
| Speakers | Audio output |

### Storage Devices (save information)
| Device | Type |
|--------|------|
| Hard Drive (HDD/SSD) | Internal — inside the computer |
| USB Flash Drive | External — portable |
| DVD/CD | Optical disc |
| Memory Card | Used in phones and cameras |

### The CPU (Central Processing Unit)
- The "brain" of the computer
- Processes all instructions
- Faster CPU = faster computer
- Measured in GHz (Gigahertz)

### RAM (Random Access Memory)
- Temporary working memory
- More RAM = can run more programs at once
- When computer is switched off, RAM is cleared

## 📖 Lesson 6.3 — Using a Mouse & Keyboard (45 minutes)

### Mouse Actions
| Action | How To |
|--------|--------|
| **Left click** | Single press left button — selects items |
| **Double click** | Two quick left clicks — opens files/programs |
| **Right click** | Single press right button — opens context menu |
| **Click and drag** | Hold left button, move mouse, release |
| **Scroll** | Roll the scroll wheel — moves up/down the page |

### Keyboard Shortcuts (Learn These!)
| Shortcut | Action |
|----------|--------|
| Ctrl + C | Copy |
| Ctrl + V | Paste |
| Ctrl + X | Cut |
| Ctrl + Z | Undo |
| Ctrl + S | Save |
| Ctrl + P | Print |
| Ctrl + A | Select All |
| Alt + F4 | Close window |
| Windows key | Open Start Menu |

### Typing Practice
> Learners practice typing: their full name, address, and the sentence:
> "The quick brown fox jumps over the lazy dog."

This sentence uses every letter of the alphabet — excellent for learning touch typing.

## 📖 Lesson 6.4 — Navigating the Windows Desktop (45 minutes)

### Key Areas of the Windows Desktop
```
┌────────────────────────────────────────────┐
│  DESKTOP — your main workspace             │
│  Icons = shortcuts to programs/files       │
│                                            │
│                                            │
│                                            │
├────────────────────────────────────────────┤
│ TASKBAR — at the bottom of the screen     │
│ [Start] [Search] [Open Apps] ... [Clock]   │
└────────────────────────────────────────────┘
```

### How to Open a Program
1. Double-click the icon on the desktop, OR
2. Click Start Menu → search for the program name
3. Click to open

### How to Close a Program
- Click the **X** button at top-right corner
- Or press **Alt + F4**

### Creating a Folder
1. Right-click on Desktop
2. Select "New" → "Folder"
3. Type the folder name
4. Press Enter
