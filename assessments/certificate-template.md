## Certificate Numbering System

Format: `NTM-[YEAR]-[TYPE]-[SEQUENCE]`

| Type Code | Programme |
|-----------|-----------|
| SC | Short Course (2 weeks) |
| DP | Diploma (6 months) |

**Examples:**
- NTM-2026-SC-0001 (first short course certificate 2026)
- NTM-2026-DP-0001 (first diploma certificate 2026)
