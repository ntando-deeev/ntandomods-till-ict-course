**Programme:** 6-Month Diploma | **Duration:** 4 Weeks

## 🎯 Month Overview

Month 2 covers full ICT foundations — from understanding computer hardware to managing files, maintaining security, and troubleshooting basic problems. By end of month, learners are confident, independent computer users.

---

## 📚 Weekly Breakdown

### Week 5 — Computer Hardware & Software
- Inside a computer: motherboard, CPU, RAM, storage
- Types of computers: desktop, laptop, tablet, server
- Operating systems: Windows, Android, iOS
- Software vs hardware distinction
- How to install basic software safely
- Printers: setup, loading paper, replacing ink/toner, troubleshooting paper jams

### Week 6 — Windows OS Deep Dive
- Windows 10/11 interface mastery
- Control Panel and Settings
- User accounts and passwords
- Task Manager — monitoring programs and closing frozen apps
- Disk management: checking storage, deleting unnecessary files
- Windows Defender and basic antivirus protection
- Keyboard mastery: all essential shortcuts
- Touch typing practice (target: 30 words per minute)

### Week 7 — File Management & Organisation
- Creating a logical folder structure for a business
- Naming files correctly (dates, versions, clarity)
- Copy, cut, paste, move, rename, delete files
- Recycle Bin management
- Compressed files: creating and extracting ZIP files
- USB drives: safely ejecting, transferring files, storage capacity
- Backing up data: why it matters, how to do it
- Google Drive basics: upload, download, share

### Week 8 — Internet Safety & Digital Literacy
- How the internet works (simple explanation)
- Safe browsing: HTTPS vs HTTP, checking URLs
- Common online scams in Zimbabwe (fake EcoCash, phishing, WhatsApp fraud)
- Password best practices: creating and managing strong passwords
- Two-factor authentication (2FA) — why and how to use it
- Social media privacy settings
- Digital footprint: what you post online is permanent
- **Month 2 Test & Portfolio Task**
